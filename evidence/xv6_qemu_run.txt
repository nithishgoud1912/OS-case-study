Interpretation
  The unlocked run duplicates P0. P1 and P2 are still on the test free list;
  the 2/3 count means only two page IDs occur exactly once.
  The spinlock run returns P0 and P1, leaving P2 on the list, so all three
  page IDs occur exactly once.
